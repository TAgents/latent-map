What this is
The model's last block is run on the state after pass 1, 2 and 3. Pass 3 is the model's own prediction, computed again by re-reading the request the way it was first read. Passes 1 and 2 are a reading the model was never trained to give: they show what the state would produce, not how the model reasons. Computing it makes the model re-read the request, and other requests wait meanwhile.
